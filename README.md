### 🌟 Projet à la Une

#### 🚗 [Actuarial Pricing Pipeline: GLM vs XGBoost](https://github.com/VOTRE_PSEUDO/actuarial-pricing-glm-xgboost)
Pipeline complet et automatisé de tarification non-vie comparant deux approches :
- **GLM Baseline** : Binomiale Négative (Fréquence) $\times$ Log-Normale (Sévérité).
- **XGBoost** : Optimisation via la fonction de perte Tweedie ($p=1.5$).
- **Évaluation** : Indice Gini Normalisé, RMSE et MAE.
