### 🌟 Featured Project

#### 🚗 [Actuarial Pricing Pipeline: GLM vs XGBoost](https://github.com/youneskhana/actuarial-pricing-glm-xgboost)
An end-to-end automated non-life pricing pipeline comparing two approaches:
- **GLM Baseline**: Negative Binomial (Frequency) $\times$ Log-Normal (Severity).
- **XGBoost**: Optimization via Tweedie loss function ($p=1.5$).
- **Evaluation**: Normalized Gini Index, RMSE, and MAE.
